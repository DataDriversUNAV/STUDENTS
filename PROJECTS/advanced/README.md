# Advanced Investigations

One folder per investigation: `PROJECTS/advanced/topic-name-yourname/` or `topic-name-team/` (teams of up to 3).

Each investigation needs a research question, data, analysis and a written report. You present your materials at every sharing session.

| Milestone | When |
|---|---|
| Investigation proposal (question, data, method) | Sharing #1 (week 3) |
| Dataset + first exploration | Sharing #2 (week 6) |
| Semester 1 progress report | Week 7 |
| Preliminary results | Sharing #3 (week 10) |
| Results + limitations | Sharing #4 (week 13) |
| Draft report — peer review | Sharing #5 (week 16) |
| Final presentation | Showcase (week 20) |

Put each sharing-session file (slides, notebook, notes) in a `sharing/` subfolder inside your investigation, e.g. `sharing/01-proposal.pdf`, and upload it **before** the session starts.
