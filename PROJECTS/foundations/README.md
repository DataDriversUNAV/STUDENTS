# Foundations Projects

One folder per member: `PROJECTS/foundations/project-name-yourname/`.

Your project is a data-analysis project on a dataset you choose, using what you learn in the [Data Analyst in Python](https://app.datacamp.com/learn/career-tracks/data-analyst-with-python) track: pandas cleaning, EDA, visualisation and one hypothesis test.

| Milestone | When |
|---|---|
| First notebook + DataCamp progress | Sharing #1 (week 3) |
| pandas mini-analysis | Sharing #2 (week 6) |
| Project proposal | Week 7 |
| Project dataset + question | Sharing #3 (week 10) |
| Project EDA | Sharing #4 (week 13) |
| Project draft | Sharing #5 (week 16) |
| Final presentation | Showcase (week 20) |

Put each sharing-session file in a `sharing/` subfolder inside your project, e.g. `sharing/03-first-notebook.ipynb`.
