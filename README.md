# Data Drivers — Students

*Part of the [DataDriversUNAV](https://github.com/DataDriversUNAV) organization · sibling repo: [ADMIN](https://github.com/DataDriversUNAV/ADMIN)*

Welcome. This repository is the club's student hub — setup guides, the learning roadmap, the events calendar, and the `PROJECTS/` folder where you submit your work via pull request.

New here? Start with **[DOCUMENTATION/01-getting-started/00-start-here.md](DOCUMENTATION/01-getting-started/00-start-here.md)**. It walks through tool installation, Git/GitHub, the course calendar, and submitting your first project, with no assumed prior knowledge.

Admin/governance material (cronogram, marketing, partnerships, meeting notes) has moved to the separate **ADMIN** repository — you won't need it as a general member.

## How this repo is organized

- **`DOCUMENTATION/01-getting-started/`** — install Git, Python, VS Code, and learn GitHub basics.
- **`DOCUMENTATION/02-events-and-activities/`** — the full-year events calendar.
- **`PROJECTS/`** — where you submit your work via pull request.

## Quick links

- New member? Start with [DOCUMENTATION/01-getting-started/00-start-here.md](DOCUMENTATION/01-getting-started/00-start-here.md).
- Want to see what's being taught each week? [DOCUMENTATION/02-events-and-activities/upcoming-events.md](DOCUMENTATION/02-events-and-activities/upcoming-events.md) — our full-year calendar following the [DataCamp Associate Data Scientist in Python](https://www.datacamp.com/tracks/associate-data-scientist-in-python) track.
- Want to submit a project? See [PROJECTS/README.md](PROJECTS/README.md) and [CONTRIBUTING.md](CONTRIBUTING.md).

## Roles at a glance

| Role | Access |
|---|---|
| Science Collaborators | Read + review student project PRs |
| Students / General Members | Read + PR submissions to `PROJECTS/` |

Access is granted through the `members` and `mentors` teams in the DataDriversUNAV organization.
