# Data Drivers — Students

*Part of the [DataDriversUNAV](https://github.com/DataDriversUNAV) organization · sibling repo: [ADMIN](https://github.com/DataDriversUNAV/ADMIN)*

Welcome. This repository is the club's student hub — setup guides, the numbered groups, the weekly calendar, and the `PROJECTS/` folder where you submit your work via pull request.

New here? Start with **[DOCUMENTATION/01-getting-started/00-start-here.md](DOCUMENTATION/01-getting-started/00-start-here.md)**. It walks through tool installation, Git/GitHub, the course calendar, and submitting your first project, with no assumed prior knowledge.

Admin/governance material (cronogram, marketing, partnerships, meeting notes) has moved to the separate **ADMIN** repository — you won't need it as a general member.

## How this repo is organized

- **`DOCUMENTATION/01-getting-started/`** — install Git, Python, VS Code, learn GitHub basics, and the step-by-step guide to group projects.
- **`DOCUMENTATION/02-events-and-activities/`** — the full-year calendar, plus how the numbered groups and attendance work.
- **`DOCUMENTATION/03-session material/`** — slides and handouts from each session.
- **`PROJECTS/`** — where you submit your work via pull request, with one folder per group (`Grupo_1/` to `Grupo_10/`).

## Quick links

- New member? Start with [DOCUMENTATION/01-getting-started/00-start-here.md](DOCUMENTATION/01-getting-started/00-start-here.md).
- Which group are you in? [DOCUMENTATION/02-events-and-activities/groups-and-attendance.md](DOCUMENTATION/02-events-and-activities/groups-and-attendance.md). Everyone follows the [DataCamp Data Analyst in Python](https://app.datacamp.com/learn/career-tracks/data-analyst-with-python) track, and each group works on one project. **3 absences = removed from the club.**
- Want to see what happens each week? [DOCUMENTATION/02-events-and-activities/upcoming-events.md](DOCUMENTATION/02-events-and-activities/upcoming-events.md).
- Starting a project? Follow [group-project-collaboration.md](DOCUMENTATION/01-getting-started/group-project-collaboration.md) step by step, then see [PROJECTS/README.md](PROJECTS/README.md).

## Roles at a glance

| Role | Access |
|---|---|
| Science Collaborators | Read + review student project PRs |
| Students / General Members | Push to their group's branch; changes reach `main` only through a reviewed PR |

Access is granted through the `members` and `mentors` teams in the DataDriversUNAV organization.
